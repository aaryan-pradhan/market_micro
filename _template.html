Roll (1984)

1 · Roll (1984): spread from price changes

  1. Bid–ask bounce. A trade prints at the ask (a buy) or at the bid (a sell). So the traded price jumps between two levels even when the true value does not move.
  2. Serial covariance. \(\text{Cov}(\Delta p_t, \Delta p_{t-1})\) = how much one price change moves with the previous one. Bounce makes it negative: an up-bounce is followed by a down-bounce.

Roll's spread estimator

Trades happen one after another. Only the traded prices \(p_t\) are observed, not the quotes.

Question: recover the bid–ask spread \(s\) from the traded prices alone.

Key idea

The spread is hidden in the negative autocovariance. Each trade adds \(\pm s/2\) to the true value; consecutive changes share one of those terms with opposite signs, so \(\text{Cov}(\Delta p_t,\Delta p_{t-1}) = -s^2/4\).

Solution

Setup. \(m_t\) = true (efficient) value after trade \(t\). \(q_t = +1\) if trade \(t\) is a buy, \(-1\) if a sell. \(s\) = spread, constant. Assumptions: (A1) \(p_t = m_t + \tfrac{s}{2}q_t\). (A2) \(q_t = \pm1\) with probability \(\tfrac12\) each, independent over \(t\). (A3) \(\Delta m_t = m_t - m_{t-1}\) is independent over \(t\) and independent of every \(q\) (efficient market).

Claim. \(\text{Cov}(\Delta p_t, \Delta p_{t-1}) = -\tfrac{s^2}{4}\), so \(s = 2\sqrt{-\text{Cov}(\Delta p_t, \Delta p_{t-1})}\).

  1. \(\Delta p_t = \Delta m_t + \tfrac{s}{2}(q_t - q_{t-1})\).Why: subtract (A1) at \(t-1\) from (A1) at \(t\).
  2. \(\Delta p_{t-1} = \Delta m_{t-1} + \tfrac{s}{2}(q_{t-1} - q_{t-2})\).Why: step 1 with \(t\) replaced by \(t-1\).
  3. Expand the covariance term by term. Every term with a \(\Delta m\) is 0, so \(\text{Cov}(\Delta p_t,\Delta p_{t-1}) = \tfrac{s^2}{4}\,\text{Cov}(q_t - q_{t-1},\ q_{t-1} - q_{t-2})\).Why: by (A3), \(\Delta m_t\) and \(\Delta m_{t-1}\) are independent of each other and of all \(q\), and independent variables have covariance 0.
  4. \(\text{Cov}(q_t - q_{t-1},\ q_{t-1} - q_{t-2}) = \text{Cov}(q_t,q_{t-1}) - \text{Cov}(q_t,q_{t-2}) - \text{Var}(q_{t-1}) + \text{Cov}(q_{t-1},q_{t-2}) = 0 - 0 - \text{Var}(q_{t-1}) + 0\).Why: covariance is bilinear; by (A2), different \(q\)'s are independent, so their covariance is 0.
  5. \(\text{Var}(q_{t-1}) = \mathbb{E}[q^2] - (\mathbb{E}[q])^2 = 1 - 0 = 1\).Why: \(q^2 = 1\) always; \(\mathbb{E}[q] = \tfrac12(+1) + \tfrac12(-1) = 0\) by (A2).
  6. So \(\text{Cov}(\Delta p_t,\Delta p_{t-1}) = \tfrac{s^2}{4}\cdot(-1) = -\tfrac{s^2}{4}\), and solving for \(s\): \(s = 2\sqrt{-\text{Cov}(\Delta p_t,\Delta p_{t-1})}\).Why: steps 3–5; \(s > 0\), so take the positive root.

Conclusion. The effective spread is twice the square root of minus the first-order serial covariance of price changes. ∎

Exam

Gotcha: in real samples the covariance is often positive, and then \(\sqrt{\cdot}\) of a negative number is undefined. It happens when (A2)/(A3) fail: trades cluster (buys follow buys) or quotes move with order flow.

Recognize: "estimate the spread with no quote data" / "implicit spread" / "bid–ask bounce" → Roll: \(s = 2\sqrt{-\text{Cov}}\).
