# BM51002 Term Project — Avellaneda–Stoikov on NSE

**Does Optimal Market Making Survive the National Stock Exchange?**
Aaryan Pradhan (22CH3FP25), Suhani Kumari (22CH3FP16), Md Arsh Ansari (22CH3FP20). Due 30 Oct 2026 EoD.

## Deliverables → files

| Form asks for | Where it is |
|---|---|
| Title, names, brief summary | [`submission/form_answers.md`](submission/form_answers.md) |
| Final report (LaTeX, same format as the base paper) | `submission/BM51002_Term_Project_Report.pdf` (built from `report/`) |
| Dataset (uploaded later) | `submission/BM51002_Term_Project_Dataset.zip` = `data/` |

## Layout

```
project/
├── submission/      what gets uploaded: form answers, report PDF, dataset zip
├── report/          LaTeX source: main.tex, sections/, refs.bib
│   ├── figures/     generated by code (do not edit)
│   └── tables/      generated by code, incl. numbers.tex macros (do not edit)
├── data/            raw NSE one-minute bars + data dictionary
├── code/
│   ├── fetch_data.py   download the bars (one-off; Yahoo keeps ~30 days)
│   ├── run_all.py      rebuild every figure, table and number
│   ├── asmm/           the analysis package, one module per step of the paper
│   └── tests/          five checks against known results
├── papers/          the base paper (Amargós 2026)
└── optimal_market_making/   earlier decks on the same model
```

## Rebuild everything

```bash
cd project
pip install -r code/requirements.txt
python code/tests/test_asmm.py      # five checks
python code/run_all.py              # ~1 min; --cached to only redraw
tectonic report/main.tex            # report/main.pdf
cp report/main.pdf submission/BM51002_Term_Project_Report.pdf
```
